## 关键复核说明

### 历史会话（本次重点）
- 复现：旧算法夹具证明失败轮次会借用后续成功答案、同一记录被取出两次。
- 修复：`pairHistory` 严格两遍配对（message_id → 唯一精确正文），绝不重复分配；无法确定则保留原名与真实状态；
  旧版本重复写入的同文答案折叠一次。
- 验证：9 条夹具、API 级不变量（`history-live-check.json`）、浏览器刷新/切线程/重新登录回归（`history-browser.json`，6/6）。

### 技术栈实际接入
- CopilotKit Runtime v2 已接入 `/api/copilotkit`（每请求构造 `LangGraphHttpAgent`，注入服务端身份），
  真实浏览器问答/引用/历史均经该运行时；包内 log 出现 `[CopilotKit Runtime]`，SSE 含标准 AG-UI 事件。
- Ragas 0.4.3 官方 `evaluate` 已实际运行（辅助判分，见评测报告），指标配置、逐题输出与限制已记录。
- 模型网关保留为薄适配：opencode-go 需注入 `x-opencode-session`、无 embedding 端点；网关只做代理/本地 embedding/用量记录。
- 重排默认 `BAAI/bge-reranker-base`（中文实测优于上游 FlashRank 多语言），FlashRank 可切换；配置、来源、评测说明一致。

### 评测口径
- 明确区分：任务完成率、全量题目分母（失败保留）、成功题分母；关键词命中≠准确率；引用存在≠语义支持；
  结构校验（引用可解析/原文逐字一致）与语义判断（Ragas 辅助 + 人工复核）分开报告。
- v0.1.1 结果见 `evaluation-summary-v0.1.1.md`：
  - 完成率：B0 24/24、B1 23/24、B2 23/24（失败题保留在总体分母）；
  - 证据召回（全量/成功题）：B0 38/51、B1 41/51 与 41/48、B2 43/51 与 43/48；
  - 引用可解析且范围正确：三组成功题均 100%，全量 24/24、23/24、23/24；
  - 决定标签匹配（成功题）：79.2% / 87.0% / 95.7%；结论关键词命中（成功题）：91.7% / 95.7% / 100%；
  - 延迟 p50/p95：26/87s、34/67s、37/205s；
  - 来源逐字核验：B0 54/54、B1 52/52、B2 55/55，越项目引用 0；
  - 人工复核 6 例：4 全支持、1 部分支持、1 失败排除；Ragas 辅助结果见 `ragas-results.json`。

   （构建 R2R/Agent/Web 镜像预计超出可用空间）限制。已实测数据库初始化与模型网关容器，其余记录为受阻。
2. **宿主机挂起期间调度自动唤醒**：未证明（v0.1 窗口期间宿主机挂起约 6 小时）。
3. 旧版本（无账号绑定）线程历史无法恢复：界面提示并新建会话。
