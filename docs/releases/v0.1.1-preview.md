# v0.1.1 预览版

会议记录助手的可运行预览版：导入文字会议记录，限定项目或会议范围提问，并从回答跳转到原文依据。

## 本版内容

- 会议记录批量导入，逐文件展示处理结果与重复提示。
- 事实检索与决定核对两条路径，区分提议、确认、变更及未知信息。
- CopilotKit Runtime 接入现有 Web，使用 AG-UI 传递流式状态与结构化回答。
- 回答默认展示结论，可展开来源、核对详情与诊断信息。
- 修复历史问题与回答错配、重复答案、刷新后状态显示不一致；历史记录按消息 ID 优先匹配，旧数据只在文本唯一匹配时关联。
- 修复容器网络监听、数据库角色密码初始化、R2R 配置渲染及健康检查配置。

截图见 [README](../../README.md)，上手见[安装文档](../usage/install.md)和[演示步骤](../usage/demo.md)。

## 评测与部署状态

- **规则评测**：使用 18 份模拟会议、24 道冻结题，比较 B0 纯向量、B1 加入重排、B2 加入完整会议核对。[v0.1.1 报告](../evidence/evaluation-summary-v0.1.1.md)记录完成数为 24/24、23/24、23/24，失败题保留在全量分母；关键词命中不是语义准确率。本次发布核对了已有报告，没有重新调用模型跑全量评测。
- **Ragas**：已有 [2 个样本的实际输出](../evidence/ragas-results.json)。Faithfulness 仅 1 个有效分数（0.143），另 1 个判分失败；Context precision 有 2 个有效分数（均值 0.750）。判分模型与生成模型同源，且输入只含最终引用片段，结果只作为试跑记录，不代表全量问答质量。
- **本机进程部署**：已有运行与验收记录。安装脚本依赖 Debian / Ubuntu 软件包工具及 PostgreSQL 18 软件源，跨发行版兼容性尚未验证。
- **Docker Compose**：提供配置和修复代码，完整的空卷安装、导入、问答、重启恢复仍待验证，因此本版标记为预览版。

## 使用范围

面向个人本地单账号，接收 UTF-8 TXT / Markdown；暂不包含语音转写、自动入会、团队权限或任务派发。Embedding 与重排在本地执行，生成回答需要调用外部模型 API。
