## 操作与证据

### A01 导入正常记录

- **前置资源**：真实 R2R + embedding + 浏览器。
- **步骤**：新建项目，分别导入中文 TXT 和 Markdown，填写标题、日期和类型，刷新列表并查看片段。
- **通过标准**：只有成功入库、存在块且归属正确才可查询；原件与关键字段一致，能查看和检索。
- **证据**：UI 操作记录、文档/chunk/collection 去敏响应、原件摘要。
- **当前结果**：NOT_RUN。

### A02 错误输入与重复导入

- **前置资源**：真实入库 + 可控超时。
- **步骤**：测试空文件、错误编码、缺字段、同名异内容、同文异项目、重复与并发提交、上传响应丢失后重试。
- **通过标准**：输入错误在模型调用前阻止；不同记录不覆盖；同一导入不重复创建；结果未知先查状态。
- **证据**：各输入、期望 ID、实际 ID/状态、请求次数与失败原因。
- **当前结果**：NOT_RUN。

### A03 项目隔离与范围过滤

- **前置资源**：两个含相同句子的项目。
- **步骤**：在项目 A 提问，诱导命中 B；修改客户端 document ID、过滤、用户身份和服务返回的范围外结果。
- **通过标准**：检索及引用仅来自服务器确认范围；不能回退全库或靠前端过滤假隔离。
- **证据**：请求范围、服务器快照、返回来源集合和拒绝样例。
- **当前结果**：NOT_RUN。

### A04 跨会议事实与分工

- **前置资源**：真实模型 + 分散信息样本。
- **步骤**：负责人和截止描述分别位于不同会议，询问完整分工。
- **通过标准**：找全必需证据；不从参与人名单补负责人，不擅自将相对时间换算成无依据的日期。
- **证据**：问题、原文必需片段、回答及逐项来源。
- **当前结果**：NOT_RUN。

### A05 提议与最终确认

- **前置资源**：真实模型 + 三次会议。
- **步骤**：先提议 A，后明确确认 B，最新会议再建议考虑 A；询问最后决定。
- **通过标准**：仍回答 B，解释最新 A 属于建议，覆盖全部选定会议。
- **证据**：按时间的原文、coverage、claims 与引用。
- **当前结果**：NOT_RUN。

### A06 明确变更

- **前置资源**：真实模型 + 前后记录。
- **步骤**：记录中明确从 A 改为 B，询问当前方案和变更过程。
- **通过标准**：显示原确认、后续替代和记录中明确理由；当前状态正确。
- **证据**：前后证据、变更 claim 及引用。
- **当前结果**：NOT_RUN。

### A07 分工不能推出完成

- **前置资源**：真实模型 + 仅分工记录。
- **步骤**：记录只写由某人负责，询问任务是否已经完成。
- **通过标准**：说明完成状态未记载，不把负责人、截止时间或计划写成完成事实。
- **证据**：问题、原文、答案、禁止推断标记。
- **当前结果**：NOT_RUN。

### A08 原因未记载

- **前置资源**：真实模型 + 无原因变更。
- **步骤**：明确变更但原文没有原因，追问为什么改。
- **通过标准**：可以说明变更，明确原因未知，不用常识或旧聊天编造理由。
- **证据**：变更证据及 unknown 输出。
- **当前结果**：NOT_RUN。

### A09 稳定引用身份

- **通过标准**：显示编号始终映射正确 document/chunk；精确片段存在，不按文本相同猜来源。
- **证据**：重排前后 ID、AnswerRecord 映射、点击后源 ID。
- **当前结果**：NOT_RUN。

### A10 引用定位与刷新

- **前置资源**：浏览器 + 多页 chunks。
- **步骤**：引用跨分页片段，查看相邻块，刷新后再点击同一引用。
- **通过标准**：定位片段和 chunk ID 正确；重叠分块不伪装成原文件；编号和引用持久不变；键盘可用。
- **证据**：刷新前后映射、分页响应、浏览器录屏或截图。
- **当前结果**：NOT_RUN。

### A11 追问与澄清

- **前置资源**：真实模型 + 同名/代词样本。
- **步骤**：对上轮议题用代词追问；另造同名人物或模糊对象，给出澄清后继续。
- **通过标准**：必要指代正确；存在实质歧义先澄清；恢复前重新核验范围，历史不被当作事实依据。
- **证据**：连续轮次、interrupt/resume 状态、当前来源。
- **当前结果**：NOT_RUN。

### A12 正常重启恢复

- **通过标准**：已完成会话、当时范围、答案与来源恢复；未完成轮次不伪装完成。
- **证据**：停启命令、前后记录摘要、浏览器验证。
- **当前结果**：NOT_RUN。

### A13 删除与部分失败

- **前置资源**：真实 R2R 文件存储 + 历史引用。
- **步骤**：移除已被引用会议，复查下载/文档/检索，再提问并打开旧引用；注入一次清理部分失败后重试。
- **通过标准**：新查询不使用该记录；旧文本保留且引用失效；原件/块清理有证据；部分失败不报全部成功，其他记录不受影响。
- **证据**：删除前后状态、下载/检索响应、旧引用展示、重试记录。
- **当前结果**：NOT_RUN。

### A14 全部与显式范围

- **前置资源**：两个独立模式的会话。
- **步骤**：all_ready 和 explicit 分别提问后新增会议，再次提问；运行中新增会议另测。
- **通过标准**：全部模式下一轮纳入新记录，显式模式不自行扩大；单轮范围固定，新记录不悄悄混入。
- **证据**：各轮 ScopeSnapshot、日期范围、来源 ID 集。
- **当前结果**：NOT_RUN。

### A15 故障与阅读预算

- **通过标准**：给出真实故障；不冒充无证据/最终结论；预算不足要求缩小范围；重试有限。
- **证据**：故障注入方式、调用次数、用户提示和未完成状态。
