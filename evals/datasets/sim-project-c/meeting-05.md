# 模拟项目C：青禾医疗 · 会议 05

- 项目：模拟项目C：青禾医疗
- 会议名称：青禾医疗 医保结算接口对齐会（上午场纪要）
- 会议日期：2026-05-12
- 记录类型：minutes（人工纪要）
- 参与人：张倩（信息科工程师）、叶清（门诊部主任）、唐磊（财务）

## 讨论

张倩说明这次对齐会要解决医保结算接口改造的归属问题，因为窗口同事已经在按新流程培训，如果接口归属不清，测试环境就没有稳定的联调对象。

叶清从窗口操作角度补充，收费窗口需要同时支持医保与自费两条结算路径，改造涉及退费与对账两个环节，测试必须覆盖月末对账场景，否则财务无法验收。

唐磊说明本次改造不新增硬件预算，涉及的费用主要是对接测试与接口变更的外部支持费用，具体金额要等医保中心给出接口变更清单后才能确认。

张倩介绍了双方确认的分工，认为医保中心熟悉结算规则，信息科熟悉院内流程，两边需要坐在一起把接口变更一条条对齐，否则单方面实现容易出现对不上的字段。她认为这个改造应当由双方联合承担。

会议还讨论了联调窗口，张倩建议在六月中旬安排，因为门诊量相对平稳，叶清补充说月中还有一次系统升级演练，需要避开。

## 决议

- 结论：医保结算接口改造由信息科与医保中心联合开发。
- 结论：联调窗口安排在六月中旬，避开月中系统升级演练。
- 待办：张倩向医保中心索取接口变更清单，唐磊在清单到位后确认费用。
- 备注：本次记录只写明日期，未标注具体开始时间。
