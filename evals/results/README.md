# 评测结果目录

本目录用于存放**真实运行**产生的结果，当前没有任何评测分数。

- 每次运行会新建一个 `evals/results/<run-id>/` 子目录，包含 `per_case.jsonl` 与 `summary.json`。
- 运行命令见 [`../README.md`](../README.md)；未真实运行前不得在此写入占位分数或替身结果。
- 本目录默认被 `.gitignore` 忽略（`/evals/results/*`，仅保留本说明文件）；对外发布前需去敏，
  只挑选去敏后有意义的结果发布。
- 真实跑分属于 T022（真实中文模型与冻结评测），由集成本人执行。
